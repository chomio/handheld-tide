# 손안의 조수 · Handheld Tide

터치, 마우스 이동, 기울기에 반응해 빛의 파동과 잔상을 남기는 웹 기반 미디어 아트 작품입니다.

## 감상 방법

`index.html` 파일을 브라우저에서 열면 됩니다. 모바일에서는 시작 버튼을 누른 뒤 화면을 터치하거나 기기를 기울여 보세요. iPhone/iPad는 기울기 감지를 허용할지 묻는 창이 나타날 수 있습니다.

## 제어

- 화면 터치/마우스 이동: 파동 생성
- `고요로`: 남은 흔적을 천천히 가라앉힘
- 스피커 아이콘 또는 `S`: 사운드 켜기/끄기
- `Space`: 화면 중앙에 파동 생성

## 배포

GitHub Pages로 배포하면 QR 코드나 링크만으로 작품을 전시할 수 있습니다. 저장소의 **Settings → Pages → Deploy from a branch → main / root**를 선택하면 됩니다.
