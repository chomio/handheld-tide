# 기억하는 연못 · A Pool That Remembers

관객의 터치, 마우스, 휴대폰 기울기에 반응해 유영하는 비단잉어와 파문을 만드는 웹 기반 미디어 아트 작품입니다. 손끝으로 만든 파문은 시간이 지나도 화면에 남아, 다음 움직임의 물살에 섞입니다.

## 실행

```powershell
cd "C:\Users\김규호\Desktop\학자세\sonanui-josu"
python -m http.server 8080
```

브라우저에서 `http://localhost:8080`을 엽니다.

## 감상 방식

- `연못에 닿기`: 작품 시작
- 터치 / 클릭: 물결 생성
- 마우스 이동: 잉어의 유영 방향 변화
- 스마트폰 기울기: 잉어와 물살의 미세한 이동
- `고요로`: 남은 파문을 가라앉힘
- `Space`: 화면 중앙에 파문 생성
